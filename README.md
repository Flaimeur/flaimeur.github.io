# Portfolio · Bilal Lachkar (Flaimeur)

🌐 **En ligne : [flaimeur.github.io](https://flaimeur.github.io/)**

Portfolio personnel : projets, expérience, compétences et contact.

- Site statique en HTML, CSS et JavaScript, sans framework ni build
- Thème clair et sombre (suit le système, mémorisé au clic), responsive, accessible au clavier
- Formulaire de contact relié à Discord via un petit serveur Node.js hébergé sur [Render](https://render.com)

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.
